# Amazon UI Automation with Playwright

A Playwright-based automation project for validating key Amazon India homepage and footer navigation flows using the Page Object Model (POM) pattern.

## Overview

This project is designed to automate browser-based checks on Amazon's homepage and navigation components, helping verify that key pages load correctly and that user actions redirect to expected URLs.

## Features

- Automated homepage validation
- Side menu interaction checks
- Footer link navigation verification
- Redirect validation for Amazon informational and social pages
- Structured Page Object Model implementation
- HTML test reporting

## Tech Stack

- TypeScript
- Playwright Test
- Node.js
- Page Object Model (POM)

## Prerequisites

Before running the tests, ensure the following are installed:

- Node.js 18 or later
- npm

## Installation

Clone the project and install dependencies:

```bash
npm install
```

Install Playwright browsers:

```bash
npx playwright install
```

## Configuration

The main config file is `playwright.config.ts`.

Current setup includes:

- Test directory: `./tests`
- Project: `chromium`
- Browser mode: visible (`headless: false`)
- Reporter: HTML
- Trace: enabled on retry

## Running Tests

Run the full test suite:

```bash
npx playwright test
```

Run a single test file:

```bash
npx playwright test tests/home.spec.ts
```

Run a specific test by name:

```bash
npx playwright test -g "User Landed on the amazon homepage"
```

Open the generated HTML report:

```bash
npx playwright show-report
```

## Test Coverage

The current automation covers:

- homepage loading
- side-menu expansion
- About Amazon navigation
- Careers navigation
- Press Release navigation
- Amazon Science navigation
- Facebook, Twitter, and Instagram redirects
- Sell on Amazon and seller-related pages

## Best Practices

- Keep selectors and page interactions inside page object files under `pom/`
- Keep test scenarios in `tests/`
- Use readable test names for easier debugging
- Reuse helper methods instead of duplicating logic

## Troubleshooting

If browsers are missing:

```bash
npx playwright install
```

If dependencies are not installed:

```bash
npm install
```

If a page fails to load or a selector is stale, check the HTML report and trace output generated by Playwright.

## Notes

This project is intended for local browser automation and is currently configured to run in a visible browser window rather than headless mode. This is useful for debugging but may need adjustment for CI or remote environments.
